## 📂 Featured Networking Lab Projects

### 1. [Multi-Department Enterprise Campus Network Architecture](./projects/01-enterprise-campus-network)
* **Simulation Tool:** Cisco Packet Tracer
* **Key Technologies:** VLANs, 802.1Q Trunking, Router-on-a-Stick, Single-Area OSPFv2, Extended ACLs, Dynamic PAT, Port Security, SSH v2
* **Architecture:**
  - Structured multi-tier campus network connecting 5 isolated departments (Management, IT, HR, Accounts, Guest).
  - Deployed Cisco Catalyst 2960 switches with 802.1Q trunks and Rapid Spanning Tree Protocol (RSTP) to eliminate switching loops.
  - Configured core Cisco 2911 ISR routers running Single-Area OSPFv2 (Area 0) with passive interfaces on LAN subnets.
  - Implemented Extended ACLs to secure sensitive finance/database subnets while allowing outbound web and DNS traffic.
  - Enforced device hardening: disabled Telnet, enabled SSH v2, encrypted console/VTY lines, and enabled MAC sticky port security.

### 2. [Edge WAN Routing & BGP Multihoming Simulation](./projects/02-bgp-dual-isp-wan)
* **Simulation Tool:** Cisco Packet Tracer
* **Key Technologies:** External BGP (eBGP), Dual-ISP Uplinks, Centralized DHCP Server, IP Helper-Address, DNS, Wireshark
* **Highlights:**
  - Simulated dual-ISP WAN edge connectivity using eBGP peering across distinct Autonomous Systems (AS 65001 & AS 65002).
  - Injected dynamic default routes to ensure fault tolerance and automatic WAN link failover.
  - Configured centralized DHCP pools on routers to dynamically lease IP addresses to 150+ workstations across multiple subnets.
  - Analyzed TCP 3-way handshakes, ARP resolutions, and ICMP messaging using Wireshark and Packet Tracer simulation mode.

### 3. [Security Operations Center (SOC) Alert Triage & Incident Monitoring Lab](./projects/03-wireshark-security-monitoring)
* **Environment:** Kali Linux, Wireshark, MITRE ATT&CK
* **Highlights:**
  - Simulated network reconnaissance scans (Nmap SYN stealth) and analyzed captured `.pcap` files in Wireshark.
  - Correlated anomalous packet behavior with the MITRE ATT&CK matrix to formulate Level-1 incident response documentation.
